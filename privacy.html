Privacy Policy

Today Stock Shorts (AI Shorts Factory) · Last updated: 2026-11-13

1. Summary

The tool runs entirely on the user's own Windows PC. The developer does not operate a server for the tool and does not receive, collect, share or sell any personal data.

2. Google / YouTube data

When the user connects YouTube, the tool requests only the youtube.upload permission through Google's official OAuth sign-in. It receives a refresh token, which is stored only on the user's PC in the Windows Credential Manager, and uses it only to upload videos the user chooses to the user's own YouTube channel. The tool does not read the user's other YouTube or Google data. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. Instagram / Facebook data

When the user connects Instagram/Facebook, the tool stores the access token, Page ID and Instagram account ID only in the Windows Credential Manager on the user's PC, and uses them only to publish videos the user chooses to the user's own accounts.

4. Other services and files

Videos are created and stored on the user's PC. The tool also uses public data APIs (DART disclosures, public stock prices, news headlines) with the user's own API keys, which are likewise stored only in the Windows Credential Manager.

5. Deleting data

The user can remove stored connection data with "Disconnect" in the tool's settings and revoke access in each platform's account settings (Google: myaccount.google.com/permissions). Uninstalling the tool deletes its files.

6. Children

The tool is not intended for children.

7. Changes

This policy may be updated; the date above shows the latest version.

Today Stock Shorts

AI Shorts Factory · private desktop tool

Today Stock Shorts (AI Shorts Factory) is a private Windows desktop tool used by its owner and a few invited acquaintances. It turns public stock disclosures (Korea's official DART system) into short vertical videos and, when the user chooses, uploads a finished video to the user's own channels through the platforms' official APIs (YouTube Data API, Instagram and Facebook Graph API).

  • Content source: official public disclosures, with the source and date shown in every video.
  • Videos are marked as AI-generated (AI voice and AI-made visuals) and are not investment advice.
  • The tool never asks for or stores passwords. Sign-in happens on each platform's official login page.
  • The tool runs on the user's PC; the developer operates no server and receives no user data.
